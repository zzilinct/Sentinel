Sentinel 1.20.3 Argus: a faster web app, a lighter caution mark, and steadier tests

Speed:
• The web app opens faster: each page loads its own code when you open it, the fonts carry only the letters Sentinel shows, and the first view draws sooner.

Colour:
• On light pages the caution mask is yellow with a thin dark outline, lighter than warning and danger.
• The caution warning card loses its solid yellow circle.

Galaxy:
• The galaxy keeps a card held under a resting mouse.

Wallet guard:
• Wallet guard reads the clipboard sooner, so a very fast swap is less likely to slip past.

Live scanning:
• Live scanning marks fooled by a repaint are now checked in a real end-to-end run.

Behind the scenes:
• Tests no longer fail at random, and test machines keep the build they test.
