Sentinel 1.8.3: gentler on your PC, and nothing it removes is gone for good

**Protection that never guesses**
• When Windows will not let Sentinel read a startup program, Sentinel now asks Microsoft Defender whether it really caught that file before touching anything. Before, a program stored in OneDrive could lose its startup entry while OneDrive was paused.
• Quarantine checks the file again first. If a different file has been saved under the same name since, it is left alone.
• Restore now brings back everything Sentinel removed, including Startup shortcuts and scheduled tasks, and never overwrites a newer file with the same name. A program you restore is not flagged again after a restart.

**Gaming and performance**
• Live scanning only listens to your mouse while it has marks on screen. Before, a high-polling gaming mouse woke Sentinel thousands of times a second even during games.
• Automatic updates wait until you have been away for at least two minutes and nothing is fullscreen, so an update never starts in the middle of a game. An update that fails twice is left for you to install.
• If live scanning cannot start on your PC, Sentinel tries again more and more slowly instead of every few seconds.

**Reliability**
• Settings are saved safely: a crash or power cut while saving no longer signs you out or resets your settings.
• If OneDrive has moved your Desktop, Sentinel now watches the real one.
