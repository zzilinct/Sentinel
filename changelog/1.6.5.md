Sentinel 1.6.5: updates that install, smooth live marks, inbox checks (released)

The Windows app release is available and the website is updated.

**Updates**
• Fixed "Restart to update" restarting into the same version. The app now checks the downloaded installer against the release's fingerprint, installs it into the folder Sentinel already lives in, and clears a stuck download if an update does not take.
• Uninstalling or updating now removes only Sentinel's own files, never other files in the install folder.

**Live scanning**
• Fixed live scanning stalling since 1.6.0: the background reader could stop at its first step and wait, so pages and results went unchecked.
• Fixed the scanner giving up on a slow first start while it was still working.
• Marks move with the page while you scroll instead of jumping into place afterwards.
• Works in whichever tab you are looking at, not only the first one you opened.
• New: in Gmail and Outlook on the web, Sentinel checks the messages in your inbox list and marks likely scams before you open them. It reads only what the inbox already shows (sender, subject, preview), never opens or marks anything as read. Pro and up.
• Switching from fast to delicate re-checks results instead of keeping the fast answers.
• A slow DNS lookup no longer counts against a site, and delicate scans no longer wait on slower full scans.

**Fixes**
• Clicking the Sentinel logo in the app stays in the app instead of opening the download page.
• Free accounts now see their 15 weekly minutes of fast live scanning in the sidebar, instead of "Locked".
• Live scanning controls no longer stop responding after the panel refreshes.
• Warning pop-ups no longer take the keyboard from what you are typing, and a startup error no longer pops up again on every retry.
• Quarantine works when the quarantine folder is on a different drive.
• Sign-in hardening: return links can only go to Sentinel's own pages, Google sign-in needs a verified email, and an account lock no longer re-locks on the first typo after it expires.
• Pressing Back or reloading a finished link scan no longer uses up another scan.
• Plan wording across the site, app and extension now matches what each plan includes.

Validation: All 136 automated tests passed, including new regression tests for the updater, tabs, scroll tracking, inbox parsing, sign-in and the live reader. A Windows 11 test machine caught both live-scanning fixes above before release.
