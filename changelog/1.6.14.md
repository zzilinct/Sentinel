Sentinel 1.6.14: Defense only acts on its own when it has proof

**Defense**
• Sentinel no longer ends or removes a startup program just because it looks suspicious. Plenty of honest programs are unsigned (game mods, AutoHotkey scripts, tools people build themselves), and removing them broke things people rely on. Now you get a notification and a Quarantine button, and you decide.
• A suspicious new file is still moved to quarantine, where you can put it back, but nothing running is ended and no startup entry is removed.
• Programs on a known-malware list are still stopped, quarantined and removed from startup straight away.
• Files are checked in the background, so Defense never slows down the rest of Sentinel.

**Also**
• One notification per dangerous file. Download protection and Defense both watch Downloads, and each used to send its own.

Validation: All 168 automated tests passed on GitHub's Windows test machines, and download protection, live scanning and inbox checks were tested end to end on a real Windows desktop.
