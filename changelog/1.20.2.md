Sentinel 1.20.2 Argus: a true caution yellow, a lighter web app on phones, and stronger security

Colour and brand:
• Caution is now a true yellow everywhere. On light pages it is a yellow mark beside dark words, never mistaken for gold or green.
• Caution never looks louder than danger.
• Warning orange and the companion's colours read clearly on every background.
• The tab icon on high-resolution screens is drawn pixel by pixel, so the mask's eyes show.

Speed:
• Phones opening the web app no longer download the 3D mask and model list they never show, about 540 KB less per visit.
• The computer app shows its main content sooner.

Live scanning:
• Marks fooled by a repaint slide back in under a second and stay visible.

Security:
• Passwords set from now on need 15 characters. A few unrelated words work well. Existing passwords keep working.
• The Windows app release build shuts more ways other programs could misuse it.
• Releases carry signed build provenance.
• The browser companion checks who sends every message.

Settings:
• Settings tells you once when another device's newer choice replaced yours.
