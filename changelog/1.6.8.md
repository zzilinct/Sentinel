Sentinel 1.6.8: Sentinel stays out of your way (released)

The Windows app release is available and the website is updated.

**Lighter on your computer**
• Every part of Sentinel now runs at below-normal priority, so games and everything else you are doing always come first.
• Defense no longer scans your Temp folder. Game launchers, browsers and Discord keep thousands of program files there, and Sentinel was re-reading them every 20 seconds, which could cause stutter in games. Downloads, Desktop and your startup programs are still protected.
• Live scanning rests properly while a game or any non-browser window is in front: one quiet check per second instead of a busy loop.

**Fixes**
• Only one copy of Sentinel can start with Windows. If an older copy existed somewhere else on the computer, the two could take turns rewriting the startup entry, and the older one (with older behaviour) started at login.
• Sentinel's own test samples no longer set off Windows Defender on developer machines.

Validation: the full automated test suite passed on GitHub's Windows test machines.
