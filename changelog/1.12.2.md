Sentinel 1.12.2 Argus: polish for the ten new protections

Every one of the ten 1.12.0 features was reviewed and tested on a real Windows machine. This release fixes what turned up.

Safer and more honest:
• QR code checker: Wi-Fi passwords, two-step sign-in secrets and app sign-in tokens in a code are now removed before anything leaves your computer.
• Try a link on the website no longer says "No threats found" when it could not check the threat lists. It says "No warning signs in the address" and that the threat lists are checked in the app.
• Tech-support scam shield:
  - "End the connection" now checks that the program really closed. If it is installed as a service, Sentinel tells you to go offline and offers to close it as administrator.
  - Trusting a program takes a second step, and needs the PIN when the parent lock is on.
  - The way out of a full-screen page takes the keyboard and appears on the right screen.
  - An ordinary full-screen video is no longer called a fake virus alert.
• Parent lock:
  - Putting back a quarantined file and switching accounts now need the PIN.
  - Each wrong-PIN wait is longer than the last.
  - The panel says honestly what the lock can and cannot stop.
• Exposure alerts:
  - Turning them off really erases everything, and says so if it could not.
  - The day you visited a site is shown in your own time zone.

Fewer false alarms:
• Stop pasted commands no longer stops ordinary code snippets (a "$ " prompt, a "# verify the checksum" comment). A command copied in another program is mentioned, not swapped. When you copy a command yourself in the browser, you get a small notice with "Copy it anyway" instead of a full-screen block. A "Put it back" button now sits under the switch.
• Check my texts no longer flags "Reply Y to activate text alerts" or real toll reminders from a short code. It only reads the Messages tab, and its links no longer use up live-scanning time.
• The browser checkup no longer flags Firefox's own built-in add-ons. It now also reads Opera and Opera GX and Firefox's search engine. It gives the right removal steps for each kind of add-on, and it no longer freezes the app while it reads.
• The password alarm keeps working with "show password" boxes and several accounts per company. The real-site button now says "I use this password here on purpose".

Easier to find:
• The recovery guide now opens inside the app, and it is linked from the shield, the password alarm, the companion's warnings and exposure alerts, already ticked for what happened.
• The home page and the download page show the new protections.
• QR result cards and checkup results are read out by screen readers, and the QR picture button works from the keyboard.
