Sentinel 1.18.3 Argus: fewer false alarms on real brands, and threat lists that still answer

Fewer false alarms on honest sites:
• A company's own site for its country (adidas.fr, apple.co.jp, paypal.com.au) is no longer treated as borrowing that company's name. On the cheap throwaway endings scammers buy in bulk (such as .tk and .ml), it still is.
• Medscape is no longer read as a misspelled Medicare.
• Telegraph pages (telegra.ph) are now known as Telegram's own publishing site, not a misspelled Telegram. What people post there is still checked like any user page.

Still caught:
• Look-alike spellings such as medlcare, teiegram, medicrae or telegrma are still flagged as copies of the real names.
• A name written with "rn" for "m" (rnedicare) is now flagged as a look-alike, not only as a borrowed name.

Threat lists:
• The URLhaus list of malware downloads moved behind a sign-up at abuse.ch. Sentinel now reads the same list from malware-filter, which publishes it freely twice a day.
• ThreatFox now needs a sign-up too, so Sentinel no longer downloads it. What it listed before is cleared, so no site stays marked by a list that is no longer read.
• PhishTank is now fetched over a secure connection.
• When a list has moved away for good, Sentinel says so once and waits its normal time before asking again, instead of retrying every hour.
