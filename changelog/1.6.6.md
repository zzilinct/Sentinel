Sentinel 1.6.6: the scanner always starts (released)

The Windows app release is available and the website is updated.

• Fixed the scanner failing to start on every launch when its downloaded threat-list cache was damaged ("database disk image is malformed"). Sentinel now throws the damaged cache away and downloads the lists again. Your account, history and settings live in a separate file and are not touched.
• Found on a real computer right after 1.6.5 shipped. If Sentinel told you "scanner did not start", this is the fix.

Validation: All 137 automated tests passed, including a new one that damages the cache on disk and checks that the server still starts. It fails on 1.6.5 and passes on 1.6.6.
