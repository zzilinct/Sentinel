Sentinel 1.6.17: much lighter in the background

Measured on a Windows test machine with nothing open (no browser, nobody using it), the way Sentinel sits while you play a game or work:

**Performance**
• Sentinel used 8 to 13% of one processor core while idle. It now uses about 5%, and its main process does almost nothing at rest.
• The biggest cause: to see which browsers were open, Sentinel started a new Windows program (tasklist) every four seconds. A small helper that stays running now keeps track instead, and reports only when a browser opens or closes.
• Threat lists that have not changed since the last download are no longer imported again. Before, the largest list (about 392,000 entries) was rewritten in full every day.
• The live scanning overlay no longer keeps redrawing an invisible animation when no browser is in front.
• Defense checks the Downloads and Desktop folders without holding up the rest of Sentinel.

Validation: All 172 automated tests passed on GitHub's Windows test machines, and live scanning, inbox checks and download protection were tested end to end on a real Windows desktop.
