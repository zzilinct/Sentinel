Sentinel 1.6.17: much lighter in the background

Measured on a Windows test machine with nothing open (no browser, nobody using it), the way Sentinel sits while you play a game or work:

**Performance**
• Sentinel's main process used 2.4 to 3.6 seconds of processor time in every idle minute. It now uses about one second, and a profile of it shows almost nothing left to do at rest.
• The biggest cause: to see which browsers were open, Sentinel started a new Windows program (tasklist) every four seconds, fifteen times a minute. A small helper that stays running now keeps track instead, and reports only when a browser opens or closes.
• Threat lists are updated by their differences: only new entries are added and only vanished ones removed. Before, the largest list (about 392,000 entries) was rewritten in full every day to change a few thousand. A list that has not changed at all is not imported again.
• Started with Windows, Sentinel no longer builds its app window until you open it, so it holds one less process all day.
• The live scanning overlay no longer keeps redrawing an invisible animation when no browser is in front.
• Defense checks the Downloads and Desktop folders without holding up the rest of Sentinel.

Validation: All 173 automated tests passed on GitHub's Windows test machines, and live scanning, inbox checks and download protection were tested end to end on a real Windows desktop.
