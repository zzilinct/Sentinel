Sentinel 1.12.3 Argus: more polish for the new protections

• Exposure alerts now also hear about single scam pages, not just whole scam sites. The fastest phishing lists (OpenPhish, PhishTank, URLhaus) name pages, and those almost never reached you before. Such an alert says "a page on this site was listed", and big shared sites and long-established sites are left alone.
• The tech-support scam shield now also asks when a remote-control program that was already running gets a new connection. This works for TeamViewer, ScreenConnect and AnyDesk.
• The browser companion tells you, once, when a password is first protected ("Your Google password is now protected"). Its menu shows what the password alarm covers. The companion is now version 1.5.0.
• Browser checkup:
  - It reads Microsoft Edge's notification permissions and search engine correctly.
  - It folds add-ons with nothing to look at into one line.
• Signing out while the parent lock is on now asks for the PIN instead of half signing out.
• If Sentinel ever fails to start, it now says so and writes why to its log, instead of failing silently.
• Check my texts now says plainly that it reads English texts for now.
