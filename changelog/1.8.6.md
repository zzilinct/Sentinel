Sentinel 1.8.6: the file scanner leaves your real programs alone

**File and download protection**
• Sentinel's file scanner is now measured against real software: Windows itself and the programs installed on a Windows computer, all legitimate. Before this release 19 of 4,500 real files got a yellow "take care" (none red or orange). Now none do.
• A script is only treated as a downloader when it both fetches something and runs it, or uses a one-line trick that does both. Windows' own admin scripts, which only run commands, are no longer marked.
• Programs are no longer judged by script rules: every .NET program names the tools for downloading, and that says nothing about it. Programs keep their own checks (known malware, password and wallet stealing, process injection, keyloggers).
• A library named with dots, like Windows.Data.Pdf.dll, is no longer taken for a disguised document. A program or archive hiding behind a document name, like invoice.pdf.exe, still is.

**Measured this release**
• Real files: 4,500 of 4,500 left alone.
• Websites: 96.3% of today's phishing flagged, no false alarms on 127 popular sites or 99 real deep pages.
• Email: 46 of 46 scams flagged, none of 80 real emails.
