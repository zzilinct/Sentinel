Sentinel 1.19.4 Argus: fewer false alarms, a companion that stops scam sites first and a lighter chat safety

Fewer false alarms:
• Long and signed links on well-known sites are no longer judged by their shape or by what other people uploaded there.
• A storage bucket name is never called a scam on its words alone.
• A file is called a virus or malware only with proof.
• Defense never changes startup entries on its own.
• Signed apps that update themselves, like Discord, are no longer flagged.

Browser companion:
• It stops confirmed scam sites before they load, in Chrome and in Firefox.
• An orange warning shows over the page and leaves the page in place.
• It never downgrades a secure (https) address.
• The popup, the settings and the warning page are new, and the emoji mask is gone.

Chat safety:
• The chat reader sleeps when no chat app is in front, so it uses much less CPU and memory while you play.
• It restarts itself if it stops, and says plainly when chat is not being watched.
• In web chats, only new messages are read.
