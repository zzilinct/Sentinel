3. What Sentinel does, and what it cannot do

Sentinel looks at links, emails and files and tells you how risky they appear and why. It checks known-threat lists, runs a checklist of warning signs, compares against known scam patterns and, on some plans, fetches and inspects the page from our servers. It then shows you a colour-coded mask and the reasons behind it.

Sentinel reduces risk. It cannot remove it. Specifically:

  • A link, email or file with no mask is not guaranteed to be safe. New scams appear faster than any list can track.
  • A mask is Sentinel’s assessment of warning signs. It is not proof of wrongdoing by any person or business, and it is not a legal finding.
  • Labels such as “Possible virus” or “Likely malware” describe the evidence Sentinel found. They are not a substitute for antivirus software that inspects your whole computer.
  • Sentinel does not stop you visiting a site, opening a file or entering your details. The decision, and its consequences, stay with you.

7. The desktop app and browser companion

The desktop app runs a copy of Sentinel on your own computer and keeps its data there. It can watch your Downloads folder, check new files against known threats, and move files it flags into a quarantine folder that you control. Quarantine moves a file; it does not delete it, and you can restore it.

On Windows, the app can also read the web address of the page your browser is currently showing, using the accessibility interface Windows provides for that purpose, and warn you if that address is dangerous. It reads the address only: not the contents of the page, not form fields, and nothing you type. On a search results page it also reads the addresses of the links on screen, where they are and the title each one shows, so it can check each one and draw a mask beside it. Those marks, the gold line and the mask in the corner of the browser are drawn in a transparent window of Sentinel’s own; nothing is changed inside your browser. The app lists which browsers are installed and which are open so you can choose one to scan with. Live scanning is off until you press Start scanning, it only works while a browser is the window in front and in use, and private windows are protected without anything about them being kept.

The optional browser companion adds masks to search results and email from inside Chrome, Edge, Brave and Firefox, for people who are not using the Windows app. Every part of this can be turned off at any time.

Defense watches the places programs arrive (Downloads, Desktop, the temporary folder and the Startup folder) and the entries that start programs with Windows. When the on-device scanner flags a program as likely or confirmed malware, the app ends any process running from that file, moves the file into quarantine, and removes Run keys, Startup shortcuts and scheduled tasks that point at it. Quarantine is a move, not a deletion, and the app lists every action so you can put a file back. Defense runs as an ordinary program beside your system’s own antivirus, not instead of it. It has no kernel driver, it cannot promise to find or remove everything, and like any scanner it can be wrong in both directions. You can turn it off.

So that protection works without a sign-up, the desktop app creates one local account for the computer the first time it starts. That account exists only in the app’s own database on your computer.

The app checks for new versions and installs them itself, so you do not have to download Sentinel again. Updates come from Sentinel's own release page and are verified against a checksum before they are applied.

The Windows installer is not yet code-signed, so Windows will show a warning on first run. Each release publishes SHA-256 checksums so you can verify what you downloaded.
